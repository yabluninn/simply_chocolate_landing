# Simply Chocolate

Responsive landing page for a chocolate brand with smooth section navigation and a review modal.
## 🔗 Live Demo
https://yabluninn.github.io/simply_chocolate_landing/

## Features
- Responsive layout (mobile-first)
- Smooth scrolling navigation (header + footer)
- “Leave a review” modal:
  - open/close buttons
  - close on overlay click
  - close on `Esc`
  - page scroll disabled while modal is open

## Tech Stack
- HTML5
- CSS3 (media queries)
- Vanilla JavaScript

## Run Locally
Just open `index.html` in your browser  
(or use VS Code **Live Server** for a better dev experience).

## Notes
Navigation uses anchor links (`#home`, `#how`, `#reviews`) with smooth scrolling via `scrollIntoView`.
