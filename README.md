# Simply Chocolate

Responsive landing page for a chocolate brand with smooth section navigation and a review modal.

## Features
- Responsive layout (mobile-first)
- Smooth scrolling navigation (header + footer)
- “Leave a review” modal:
  - open/close buttons
  - close on overlay click
  - close on `Esc`
  - page scroll disabled while modal is open

## Tech Stack
- HTML5
- CSS3 (media queries)
- Vanilla JavaScript
